# 每日轨迹微信小程序

这是根据交互原型实现的原生微信小程序工程，包含：

- 每日完成记录，可选或不选关联任务
- 任务分类标签可新增、重命名和删除
- 分类标签支持从颜色板自定义颜色，不同标签可使用不同颜色
- 已建任务和今日记录可点击编辑
- 任务看板和每日记录均可按照分类标签筛选显示
- 点击任务进入任务详情子页面，查看并编辑该任务的全部事件记录
- 任务进度条从 0% 红色，经 50% 橙色连续过渡到 100% 绿色，与标签颜色无关
- 任务分类、名称、描述和进度同步
- 每个任务的执行天数（按有记录的去重日期计算）
- 最近一周、最近一月和自定义日期统计
- 成就页指标、每日柱形和项目分类均可进入对应统计明细
- 统计分布支持按任务和按标签切换；长日期区间按时间段聚合，避免抽样失真
- 成就文案根据完成量、活跃天数和推进项目自动展示充实反馈或温和鼓励
- 设置与个人账号页，可调整字号并记录基本资料
- 底部三个主板块配有普通/选中状态图标
- 最多 5 个微信账号通过临时联动码共享数据
- 可分别同步任务看板、每日记录和分类标签，或三项完全同步
- Excel `.xls` 导出
- 飞书表格云函数导出骨架
- 未配置云开发时可直接使用本地演示数据

## 立即运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`E:\BaiduSyncdisk\gpt\每日轨迹小程序`。
4. 暂时没有 AppID 时选择测试号；已有 AppID 时替换 `project.config.json` 中的 `touristappid`。
5. 点击“编译”。默认使用本地缓存，三个页面和 Excel 导出可以直接体验。

## 启用云数据库

1. 在微信开发者工具中开通云开发并创建环境。
2. 创建集合 `tasks`、`dailyRecords`、`categories`、`accountLinks` 和 `syncGroups`。
3. 将 `miniprogram/app.js` 中的 `cloudEnvId` 改成云环境 ID，并把 `useCloud` 改成 `true`。
4. 在云开发控制台配置安全规则，参考根目录的 `database.rules.json`。所有个人记录必须限制为仅创建者可读写。
5. 右键 `cloudfunctions/accountSync`，选择“上传并部署：云端安装依赖”。启用云开发后，任务、记录和标签统一通过该云函数访问，以支持多个微信账号联动。

## 多微信账号联动

1. 主微信进入“我的成就 → 设置 → 微信账号联动”，选择完全同步或部分同步。
2. 主微信生成 6 位联动码；联动码 10 分钟内有效。
3. 其他微信登录同一小程序，在相同页面输入联动码加入。
4. 一个联动组最多支持 5 个微信账号。
5. 部分同步可以单独选择任务看板、每日记录和分类标签；三项全部开启即为完全同步。
6. 昵称、头像、生日、城市和个人简介不参与同步，继续保存在各自微信本机。

## 部署飞书导出

1. 在飞书开放平台创建企业自建应用，开启云文档/表格创建与写入权限，并发布应用版本。
2. 在微信开发者工具中右键 `cloudfunctions/syncFeishu`，选择“上传并部署：云端安装依赖”。
3. 在该云函数的环境变量中配置：
   - `FEISHU_APP_ID`
   - `FEISHU_APP_SECRET`
4. 不要把飞书密钥写进小程序前端代码。

## 数据结构

### tasks

```js
{
  category: '工作',
  name: '微信小程序改版',
  description: '完成核心页面设计与开发联调',
  progress: 65,
  status: 'active',
  createdAt: Date,
  updatedAt: Date
}
```

### dailyRecords

```js
{
  taskId: '任务文档 ID，允许为空',
  category: '工作',
  title: '完成数据统计页面',
  description: '完成图表组件与空状态设计',
  progressAfter: 80,
  recordDate: '2026-08-15',
  createdAt: Date
}
```

执行天数的计算方式：筛选当前任务的全部 `dailyRecords`，对 `recordDate` 去重后计数；同一天有多条记录仍然只计算一天。

## 上线前检查

- 换成正式 AppID，补充小程序名称、图标、简介和服务类目。
- 完成真机测试，重点检查日期、跨月统计、隐私权限和弱网状态。
- 飞书接口调用前确认应用权限与接口版本。
- 上传代码，在微信公众平台配置体验版并提交审核。
